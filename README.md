# Agent Company

> **一个 agent 再强也是一个人,一个人有极限;而一家公司,能把一群智力平平的普通人——小模型——拼成一个强大的组织。**

一个多层级 Agent 组织系统的立项与设计:给"会干活的 agent 舰队"装上组织、边界、契约与治理,并且整套系统在没有任务时零进程、零 token。

## 初衷

单体 Agent 已经很强,但它终究是"一个人在干活":上下文有极限,注意力有极限,一个任务从头跟到尾,记忆被细节撑爆,思考档位高到烧钱。

真实的公司不这么运转。公司让**架构师只做架构、经理只做整合协调、工人只写自己那一小块、测试只负责验证、质检站在生产线之外**——每一层用它那个层级需要的智力就够了。把一群"普通人"(低档小模型)组织起来,靠分工、审批链、契约和账本,产出超过任何单体。

这个仓库记录把这套组织学做成可运行系统的立项过程:

- **22 条组织决策**:任务容器、动态工作边界、分级审批链、写手极简工具链、执行权集中、专家评审团、诚实宪法……
- **三角事实基础**:DeepSeek 官方 superagent 原型精读、自研 shepherd 原型深度映射、15+ 家业界方案(Anthropic / OpenAI / Google / Microsoft / MetaGPT / Manus…)版图调研
- **立项报告**:定位、概念模型、拒绝的概念表、风险登记、R1–R5 路线图

## 22 条决策一览

<details>
<summary>展开</summary>

1. 任务 = 持久容器(挂对话、记忆、状态账本,跨对话存在)
2. 工作边界 = 动态对象:agent 申请扩张文件夹 → 审批 → 持久并入 → 可收缩
3. 分级审批链:上级授权范围内代批,越界才升级到人
4. 主 agent 显式派发子文件夹给写手(git worktree)
5. 写手工具链极简:只有读文件 + 写文件,无执行权无网络
6. 执行权集中:统一测试 agent 群是唯一能跑代码的器官
7. 二级 agent 层做整合与统一分配;主 agent 只管战略架构
8. 边界审批按文件重要性分级(主 agent 定架构时生成重要性地图)
9. 云端审查 agent,在生产链之外独立验收
10. 组织三级化:CEO(主)/ 经理(二级)/ 手(写手);模型分档省钱
11. 发布-同步链:提交 → 合入主仓库 → 评审通过 → 全员同步
12. 视察权:主 agent 只读拉取状态 JSON,可蒸馏入任务账本
13. 罢免权:证据确凿 + 人类批准
14. 专家评审团:横向参谋部,出优化路径与方向建议
15. 全局诚实宪法:任何 agent 不得隐瞒;隐瞒 = 罢免证据
16. 按需激活:只拉起当前需要的 agent,用完即散;记忆存任务容器
17. 契约先行:域内契约二级定义,跨域契约专家团批准入册
18. 专家团对抗性义务:必须反驳必须找茬,反驳须附替代方案
19. 本地微型 git 同步(优先零进程 bare 仓库)
20. 同步通知 = MD 文件挂仓库边
21. 横向通信需上级审批(专家团内部自由)
22. 每域写手存量 2–3 个;任务卡带 base_commit 三路合并

附加决策:任务驱动触发,不做常驻主动找活;没任务 = 没进程零 token;专家团限频。

</details>

## 核心立场(与业界的对照)

| | 主流方案 | Agent Company |
|---|---|---|
| 层级 | 刻意压在两层 | 三级管辖 + 横向参谋部 |
| 权限 | spawn 时静态白名单 | 可审批的动态边界对象 |
| 诚实 | 系统提示词软约束 | 宪法 + 诱饵后验执法 + 罢免治理闭环 |
| 执行权 | 每个 agent 全套工具 | 集中于独立测试群 |
| 成本 | 靠开发者自觉 | 逐层字数预算 + 编制制 + 分电表 |
| 闲置 | 常驻进程待命 | 没任务 = 没进程零 token |
